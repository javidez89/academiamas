CT-GenAI · Capítulo 2

Ingenieria de prompts para las pruebas de software efectivas

Organiza estructura de prompts, tecnicas fundamentales y aplicacion practica de GenAI a analisis, diseno, implementacion, regresion, monitoreo y control de pruebas.

10 objetivos LO365 min11 términos clave

Estructura de prompts

Un prompt util define rol, contexto, instrucciones, datos de entrada, restricciones y formato de salida esperado.

  • El contexto evita respuestas genericas.
  • Las restricciones controlan alcance, formato y riesgos.
  • El formato de salida facilita revision y trazabilidad.

Tecnicas de prompting

Zero-shot, one-shot, few-shot, encadenamiento y meta-prompting permiten adaptar la ayuda de un LLM a tareas de prueba concretas.

  • Few-shot usa ejemplos.
  • El encadenamiento divide problemas complejos.
  • Meta-prompting mejora la instruccion antes de ejecutar la tarea.

Aplicacion a testing

La seleccion de tecnica depende de la tarea, el riesgo, la informacion disponible y la necesidad de verificacion humana.

  • Usa GenAI para acelerar, no para saltar analisis.
  • Valida criterios, casos, scripts y reportes.
  • Refina prompts con metricas, feedback y una tasa de exito que mida si la salida puede ejecutarse y producir el resultado esperado.

Objetivos de aprendizaje

  1. GenAI-2.1.1 · K2Ejemplificar una estructura de prompt efectiva

    Usa rol, contexto, instrucciones, datos, restricciones y formato de salida.

  2. GenAI-2.1.2 · K2Diferenciar tecnicas fundamentales de prompting

    Compara zero-shot, one-shot, few-shot, encadenamiento y meta-prompting.

  3. GenAI-2.1.3 · K2Distinguir prompt de sistema y prompt de usuario

    Explica que el sistema fija comportamiento base y el usuario define la tarea concreta.

  4. GenAI-2.2.1 · K3Aplicar GenAI al analisis de prueba

    Usa GenAI para explorar requisitos, criterios de aceptacion, condiciones y riesgos.

  5. GenAI-2.2.2 · K3Aplicar GenAI al diseno e implementacion de pruebas

    Convierte condiciones en casos, datos, pasos, scripts o escenarios verificables.

  6. GenAI-2.2.3 · K3Aplicar GenAI a regresion automatizada

    Usa prompting para apoyar scripts, pruebas por palabras clave y analisis de reportes.

  7. GenAI-2.2.4 · K3Aplicar GenAI a una tarea de monitoreo y control de pruebas

    Resume metricas, riesgos, tendencias y acciones a partir de datos de prueba.

  8. GenAI-2.2.5 · K3Seleccionar tecnicas de prompt segun contexto

    Elige tecnica, ejemplos y refinamiento considerando tarea, riesgo, dominio y evidencia.

  9. GenAI-2.3.1 · K2Resumir metricas para evaluar salidas GenAI

    Considera exactitud, cobertura, consistencia, utilidad, trazabilidad, seguridad y coste.

  10. GenAI-2.3.2 · K2Ejemplificar refinamiento iterativo de prompts

    Aplica retroalimentacion, restricciones, ejemplos y criterios para mejorar resultados.

Errores frecuentes

  • Usar GenAI sin revision humana ni trazabilidad.
  • Confundir una respuesta convincente con evidencia suficiente.
  • Ignorar privacidad, seguridad, coste o cumplimiento por enfocarse solo en velocidad.

Ejemplos aplicados

  • Ejemplo de estudio: aplica Ingenieria de prompts para las pruebas de software efectivas a una historia de usuario real y registra prompt, salida, revision y decision.
  • Ejemplo profesional: compara una tarea hecha manualmente contra una apoyada por GenAI y mide calidad, cobertura, coste y riesgo.
